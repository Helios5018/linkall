小鹤配置的本项目修改：将 `translator.dictionary` 从 `luna_pinyin` 改为 `linkinput_ice`，显式指定 `user_dict: pinyin_simp` 以沿用旧学习数据，移除 `simplifier` 过滤器，保持上游小鹤拼写代数并开启首字母简拼；修改后的 YAML 仍按该资源原有 GPL-3.0 许可提供，其作者信息保留。`default.custom.yaml` 配置三种中文方案、英文补全及默认 5 个候选；运行时三种中文方案挂载英文次翻译器，英文直通保留为独立选项。方案源文件与词典以 YAML 形式随包提供。

雾凇接入使用锁定版本的五张中文词表和两张英文词表，内容不改动，分别放在 `linkinput_ice/` 和 `linkinput_en/` 命名空间，由生成的词典按上游顺序导入。英文 schema 由本项目编写，采用 Rime 内置 table_translator 和独立 prism 支持前缀补全；大小写适配在 Swift 外壳完成。未引入 Lua、cn_en 特殊混合词条或可选语法模型。全拼同样使用 `linkinput_ice` 与原 `pinyin_simp.userdb`；五笔词典及其反查仍用原资源。词库源文件及其来源说明随 app 提供。

官方下载包的动态库校验值由 bootstrap 核对，ARM64 最低加载版本为 macOS 11；客户端部署目标为 macOS 14。二进制包含的原生依赖没有 Homebrew 动态链接。Boost 的精确编译版本尚未由官方发布物 SBOM 确认，记录为未知；已保留相应许可证，不将运行库版本凭空补齐。googletest 属于上游构建测试依赖，随附其许可不表示运行时需要它。

本项目未打包可选的 librime-lua、octagram、predict 插件或 AI 模型权重。API 服务条款与数据保留单独见 `隐私与数据流.md`。

公开分发前还需复核：预编译运行库的完整上游 SBOM、词表上游授权说明及实际 API 账户条款。当前是本机开发验证包，没有完成公证或面向其他机器的发布验收。
