## 授权、暂停与删除

本用户已明确要求保存输入与语音内容，个人构建的输入记录默认开启。截图另有开关和系统录屏授权；窗口标题与可见应用文字需要辅助功能权限；可见正文读取跟随截图开关，不独立扩大为后台文档全文采集。云端文字与音频授权独立于本地记录开关。

记录暂停不妨碍普通打字，也不等于撤销用户主动使用语音或文本 API 的授权。AX 读取限定可见字符范围和可校验位置的短文本，跳过密码字段，限制树节点与时间预算；不支持时保留 OCR。安全输入和排除应用不采集；截图过滤自身及排除应用。锁屏/休眠停止采集并清除临时草稿，已经授权保存的历史保留。

截图默认按 30 天或 100 GB 双上限清理，重要标记也受上限约束；文字、备注和来源继续保留，界面注明原图已清理。文本记录可逐条或按最近时间段删除。删除同时移除关联截图；secure_delete 与 WAL 截断不保证清除系统备份或 SSD 历史物理副本。

“清除 LinkAll 全部本地数据”是独立的显式操作，包含历史、截图、词库、配置与 API 凭据。卸载应用保留这些用户数据，应用回滚也不回退用户数据库。

## API 与剪贴板

API 密钥只存 macOS Keychain。当前文本/转写链路使用用户配置的服务；流式转写可能经过网关取得短期令牌后直连上游。应用不承诺网关或供应商“零留存”；服务端数据用途、区域和期限需按实际账户另行核对。历史不会因为启用整理而整库上传。取消或撤回相应 API 授权只能停止本机后续处理，已经发出的请求不能从远端收回；本地删除不等于删除上游数据。

语音在既定场景通过临时剪贴板和 ⌘V 交付，随后恢复剪贴板；若期间用户复制了新内容则不覆盖。无法确认目标时，结果复制到剪贴板供用户自行采用，不自动发送。

用户于 2026-10-04 授权 LinkAgent 回复建议使用当前输入框及当前应用近期记录。每次显式触发最多选 10 条、12000 字记录正文，窗口/ID/时间等元数据另计。屏幕记录是显示器截图，不能仅按 app 标签上传：新记录限制到已验证前台窗口范围；旧记录只使用已有的本窗口可见 AX 文字。历史不整库上传，取消不撤回已发出的请求。具体筛选与未知目标边界见 [回复建议](Agent回复建议.md)。对外动作和未来执行器仍需独立授权，不自动回复或运行命令。
